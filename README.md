# Hush website

Static site for the Hush iOS app, served by GitHub Pages at https://hush.zt-mobile.dev.

- `/` landing page
- `/privacy/` privacy policy (App Store Connect Privacy Policy URL)
- `/support/` support page (App Store Connect Support URL)
- `/terms/` terms of use

Plain HTML and CSS, no build step. Edit the files and push to `main`.
